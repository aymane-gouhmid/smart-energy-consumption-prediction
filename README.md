
# Smart Energy Consumption Prediction

A machine learning project for electricity consumption
analysis, forecasting, and anomaly detection.

## Objectives

- Analyze historical electricity consumption.
- Identify daily and weekly consumption patterns.
- Build and compare machine learning forecasting models.
- Evaluate prediction performance using appropriate metrics.
- Detect unusual consumption patterns.
- Develop an interactive dashboard.

## Tech Stack

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Streamlit
- FastAPI
- Pytest
